# WebApp

ASP.NET Core MVC web application demonstrating clean architecture, responsive design, and modular page structure.

## Overview

This project is a web application built using ASP.NET Core MVC. It follows a structured approach with separation of concerns between controllers, views, and models, and includes multiple pages such as services, contact, and privacy.

## Features

- MVC architecture (Controllers, Views, Models)
- Responsive user interface
- Services page
- Contact page
- Privacy page
- Clean and maintainable structure

## Tech Stack

- C#
- ASP.NET Core MVC
- HTML
- CSS
- Bootstrap (used for layout and base components, customized with custom styling)

## Project Structure

- Controllers
- Models
- Views
- wwwroot (static files)

## Getting Started

1. Open the project in Visual Studio
2. Build the solution
3. Run using HTTPS
4. Navigate through the available pages
